## 🎯 Using This Project in Your Portfolio?

We encourage you to showcase what you build! When featuring work derived from ROAMI:

### Do:
✅ Clearly state it's based on ROAMI by Mowlid Haibe  
✅ Link to the original repository  
✅ Explain what you added or changed  
✅ Give proper attribution  

### Don't:
❌ Claim you built it from scratch  
❌ Remove attribution or credits  
❌ Present it as entirely your own work  

### Example Portfolio Description:
```
Personal Travel Site (Based on ROAMI)

Built upon the open-source ROAMI framework by Mowlid Haibe, 
I customized this travel experience platform for [purpose].

Original project: github.com/mawlid1431/ROAMI

My contributions:
- Feature A
- Design change B
- Integration C
```
